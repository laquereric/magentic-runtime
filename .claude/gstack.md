# mmg-gstack — role-based sprint

**Define the role before the task.** Type a slash command to adopt a role; run the sprint in order.

Sprint: think → plan → build → review → test → ship → reflect

- **think** — `/framer` (Framer): outcome + altitude + ownership tier before anything is built
- **plan** — `/architect` (Engineering Manager): boundary-aware architecture review + test plan; contracts lead, code follows
- **plan** — `/boundary-keeper` (Boundary Keeper): enforce OWN IT / OFFICIAL / FOLLOW THEM; upstreams pinned, never forked
- **build** — `/builder` (Builder): implement at the deterministic plane; never-raise envelopes; smallest clean thing
- **review** — `/reviewer` (Reviewer): multi-lens; second independent model where available; agree=likely, diverge=human
- **review** — `/cso` (Security Reviewer): OWASP Top 10 + STRIDE; egress/boundary; flag only at confidence >= 8/10
- **test** — `/qa` (QA Lead): drive the REAL flow; verify observed behavior, not just green tests
- **ship** — `/release-manager` (Release Manager): the six gates + engines-build -> a signed evidence bundle; release_ready or not
- **reflect** — `/reflector` (Reflector): friction log + memory + evolve toward higher-level structures (CE)
